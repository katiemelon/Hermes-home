# Skills

Household skills for Hermes. Each skill is a capability your agent can use.

The bootstrap interview will recommend which skills to enable based on your household's needs. You can also add or remove skills at any time by telling Hermes.

## Included skills

| Skill | What it does |
|-------|-------------|
| `morning-briefing` | Daily summary of weather, calendar events, and reminders sent at a time you choose |
| `meal-planning` | Weekly meal suggestions and grocery list generation based on your family's preferences |
| `school-schedule` | School term dates, reminders for events, and pickup/dropoff coordination |
| `email-drafting` | Draft emails on your behalf — school communications, replies, follow-ups |
| `weekly-summary` | End-of-week household review and planning prompt for the week ahead |

## Adding your own skills

Copy any skill folder, rename it, and edit the `skill.md` file inside. Tell Hermes about it and it will pick it up automatically.
